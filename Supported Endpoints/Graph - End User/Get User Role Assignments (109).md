# Get User Role Assignments

|  |  |
| ----- | ----- |
| **OID** | 109 |
| **Name** | OAP_SOLV_002_Graph_listUserRoleAssignments |
| **Overview** | Retrieve the list of appRoleAssignments that are currently granted to a user. This operation also returns app role assignments granted to groups that the user is a direct member of. |
| **Method** | GET |
| **Path** | `https://graph.msapi.tdsynnex.com/v1.0/users/{{userId}}/appRoleAssignments` |
| **Doc** | [List Role Assignments](https://learn.microsoft.com/en-us/graph/api/user-list-approleassignments?view=graph-rest-1.0&tabs=http) |
| **Upload Package** | Common |
| **Supported** | Support for all users. |
