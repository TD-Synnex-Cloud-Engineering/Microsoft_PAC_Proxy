| ----- | ----- |
| **OID** | 108 |

| **Overview** | Read the user and organization userSettings object. |

| **Path** | `https://graph.msapi.tdsynnex.com/v1.0/users/{{userId}}/settings` |
| **Doc** | [Get User Settings](https://learn.microsoft.com/en-us/graph/api/usersettings-get?view=graph-rest-1.0&tabs=http) |
