The TD SYNNEX PAC Proxy service allows a customer to access API requests that they otherwise may not be able to access.

The primary API that is accessible is the Partner Center API. It also allows use of the Graph and Azure Management APIs in the context of a TD SYNNEX user.

For more information contact: Msft-SE-Azure-NA@tdsynnex.com

---
**Note:**
- A * by a request means it is not supported for reseller/end user access.
- A ^ by a request means it is not supported for CSP.
----

**IMPORTANT:** PAC Proxy treats the PATH as case sensitive. Using the wrong case will return a "no upstream API" error.
